# 三人团队分工、学习路线与整合方案

> 原则：各有主责但不能形成孤岛；每个关键成果至少由一名非作者复核；论文从第一天同步写。

## 一、推荐角色

| 角色 | 主责 | 交付物 | 必须具备的副能力 |
|---|---|---|---|
| 成员1：建模负责人/队长 | 拆题、假设、路线、指标、决策 | 问题树、公式、流程图、验证方案 | 能读代码结果、写模型章节 |
| 成员2：代码与数据负责人 | 数据、实现、实验、复现、制图 | 数据字典、脚本、记录、图表 | 理解假设、能解释指标 |
| 成员3：论文与验证负责人 | 主线、排版、文献、解释、核查 | 主文档、摘要、引用、核查表 | 会基础分析、能复核实验 |

论文负责人不是最后润色，建模负责人不是只写公式，代码负责人也不是机械实现。三人都要读题、参与选题并理解最终方案。

## 二、专项学习

### 成员1：建模/队长

- 变量、参数、约束、目标、假设和量纲；
- 描述统计、回归诊断、相关与因果；
- 线性/逻辑回归、树模型、时序基础；
- 线性规划、整数规划、多目标和启发式；
- 交叉验证、敏感性、稳健性和消融；
- 风险清单、截止时间、方案冻结和任务拆分。

验收：30 分钟把题拆成“输入—处理—输出—指标”，画一页路线，为每问提出基线与改进。

### 成员2：代码与数据

- Python、函数、环境与异常处理；
- pandas/numpy 清洗、连接、分组和特征；
- matplotlib/seaborn 统一制图；
- scikit-learn Pipeline、交叉验证和指标；
- 回归、分类、聚类、降维、集成模型；
- scipy、OR-Tools/PuLP 优化；
- Git 或可靠的版本、日志和复现机制。

验收：一小时形成数据审计；一键生成最终表图；换电脑能按 README 复现。

### 成员3：论文与验证

- 数模论文结构和定量摘要；
- Word/LaTeX 公式、图表、交叉引用、PDF；
- 学术检索与参考文献；
- 指标解释、误差来源、实际意义和边界；
- 基础 Python/pandas，独立复核数字；
- 单位、图例、字号、有效数字与图注；
- 符号、术语、题号、结果一致性检查。

验收：可依据实验记录独立写完整章节，且追溯每个关键数字。

## 三、全员共同底座

读题拆题；Python/Excel 数据查看；回归、分类、优化和指标基础；过拟合与数据泄漏；图表解读；官方模板和 MD5；真实引用、实验可核验及当届工具使用规范。

## 四、八周训练计划

### 第1—2周：共同语言

学习建模流程、Python 与论文结构；完成一个小型回归/分类项目；建立目录、命名和模板；每人精读一篇优秀论文。验收为 5—8 页小论文且图表可复现。

### 第3—4周：角色专项

成员1学模型选择、优化和验证；成员2学 Pipeline、时序/优化代码；成员3学摘要、排版、文献和制图。共同练 2024 C 或 2025 E 前两问。验收为 24 小时内完成审计、基线、对比和论文骨架。

### 第5—6周：第一次完整模拟

从推荐题中随机选择一道，按真实节奏完成 72—96 小时模拟，提交 PDF 和代码包。每天固定两次同步，禁止无限换模型。

### 第7周：补短板

只修最严重的三类问题；建立审计、验证、指标、绘图、优化校验代码模板，以及摘要、符号表、算法、优缺点模板。

### 第8周：第二次模拟

换一个方向做完整模拟，重点练选题、并行和整合；冻结电脑环境、包版本与备份。最终 PDF 至少提前 3 小时冻结。

## 五、比赛中的协作

### 选题

- 三人分别初读，再交叉读两道候选；
- 成员1主持统一打分；成员2做附件读取/算力测试；成员3检查证据与论文结构；
- 选定后共同写“问题—方法—指标—交付物”一页表。

### 建模实验

- 成员1把想法写成变量、公式、输入输出、约束和指标；
- 成员2先基线后主模型，结果全部落盘；
- 成员3同步写作并复算关键统计量；
- 每 6 小时短会：完成什么、结果是什么、下一风险是什么。

### 收口

- 成员1审公式、假设、约束和逻辑；
- 成员2重跑最终入口，锁定数字；
- 成员3统一全文并管理 PDF；
- 三人逐问口头答辩，答不上就是论文缺口。

## 六、整合机制

### 单一事实源

只保留一个论文主文件、一个最终结果登记表、一份数据字典和符号表；原始数据只读，处理数据由脚本生成。

每个模型的交付必须包括：题号、输入字段、预处理、公式/算法、参数依据、评价指标、结果图表、结论限制、脚本路径。

### 双人复核

- 成员1的模型由成员2查可实现性；
- 成员2的实验由成员3查划分与数字；
- 成员3的论文由成员1查逻辑、成员2查结果；
- 最终 PDF 三人各独立检查一次。

## 七、版本规范

使用 `q2_xgboost_v03.py`、`fig_q2_error_v03.png` 等名称，禁止“最终最终版2”。结果登记表包含题号、实验号、数据版本、脚本、种子、参数、指标、运行时间、图表及是否入文。每日定时备份两处。

## 八、复盘评分

每次模拟按 0—5 分评价：选题速度、答题完整性、模型合理性、代码复现性、验证质量、论文一致性、图表质量、协作交付、提交安全。优先修低于 3 分项，每次只集中解决最严重的三项。

## 九、最终责任

- 队长：通知、账号、下载、进度、决策、MD5、上传；
- 建模负责人：每问都有模型、指标和验证；
- 代码负责人：数字可复现，代码图表归档；
- 论文负责人：模板合规、全文一致、PDF 可读；
- 全体：学术诚信和最终成果共同负责。
