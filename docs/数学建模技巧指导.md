# 第一部分 题目类型划分与团队定位

## 1.1 研究生数模竞赛题目分类体系

通过对近 10 年（2014-2024）中国研究生数学建模竞赛题目的系统梳理，可将题目划分为 **5 大类型**。每类题目在数据特征、核心任务、所需模型、产出形式上均有明显差异。

### 类型一：数据驱动建模类（Data-Driven Modeling）

| 维度 | 说明 |
|---|---|
| **数据特征** | 提供大量实测/实验数据（通常 > 1000 样本），附件多、字段多 |
| **核心任务** | 分类、回归预测、因素分析、经验公式修正、最优化 |
| **典型模型** | 机器学习（RF/SVM/GBDT）、统计回归、ANOVA、NSGA-II |
| **产出形式** | 预测结果填表 + 模型对比 + 可视化 |
| **代表题目** | **2024 C**（磁芯损耗）、2023 C（碳排放）、2021 D（生物分子）、2019 D（无人机控制） |
| **难度** | 中等偏上，重在特征工程与模型选择 |

### 类型二：物理机理建模类（Mechanism-Based Modeling）

| 维度 | 说明 |
|---|---|
| **数据特征** | 数据少或无数据，依赖物理规律与微分方程 |
| **核心任务** | 建立微分方程/偏微分方程、求解初值/边值问题 |
| **典型模型** | ODE/PDE、有限元、有限差分、传热/流体方程 |
| **产出形式** | 数值解 + 相图 + 稳定性分析 |
| **代表题目** | 2024 A（雷达信号）、2022 A（火焰传播）、2018 A |
| **难度** | 高，需要扎实的物理与方程功底 |

### 类型三：运筹优化类（Operations Research）

| 维度 | 说明 |
|---|---|
| **数据特征** | 提供明确的约束条件、成本/利润参数 |
| **核心任务** | 资源分配、路径规划、调度、排班 |
| **典型模型** | 线性/整数规划、动态规划、网络流、启发式算法 |
| **产出形式** | 最优方案 + 灵敏度分析 |
| **代表题目** | 2024 B（生产调度）、2023 B（无人机协同）、2020 B |
| **难度** | 中等，重在约束建模与算法效率 |

### 类型四：评价决策类（Evaluation & Decision）

| 维度 | 说明 |
|---|---|
| **数据特征** | 多指标、多方案、含定性/定量混合 |
| **核心任务** | 指标体系构建、权重确定、方案排序 |
| **典型模型** | 层次分析（AHP）、熵权法、TOPSIS、模糊综合评价 |
| **产出形式** | 排序结果 + 一致性检验 + 敏感性分析 |
| **代表题目** | 2021 C、2019 A、2017 D |
| **难度** | 偏低，重在指标设计与合理性论证 |

### 类型五：图像/信号处理类（Signal & Image Processing）

| 维度 | 说明 |
|---|---|
| **数据特征** | 提供图像、音频、波形等非结构化数据 |
| **核心任务** | 识别、复原、分割、特征提取 |
| **典型模型** | CNN、傅里叶变换、小波变换、形态学 |
| **产出形式** | 处理结果图 + 识别准确率 |
| **代表题目** | 2024 F、2022 C（CT 图像）、2018 C |
| **难度** | 高，需要深度学习与信号处理背景 |

## 1.2 本团队专注方向：数据驱动建模类

### 选择依据

1. **题目频率高**：近 5 年每年至少 1 道题为该类型（C/D 题为主），命中率最高；

3. **可复现性强**：数据驱动建模流程标准化程度高，便于团队分工与训练；
4. **与 2024C 项目契合**：本项目已完成的 2024C 题是该类型典型代表，可作为训练样本。

### 该类型题目的识别特征

当看到以下特征时，立即判定为数据驱动建模类：

- ✅ 题目附件包含 3 个以上 Excel/CSV 数据文件
- ✅ 样本数 > 500，字段数 > 10
- ✅ 含"分类"、"预测"、"因素分析"、"修正"、"优化"等关键词
- ✅ 要求把结果填入指定表格并上传
- ✅ 提到"数据驱动"、"机器学习"、"经验公式"

### 该类型题目的 5 类标准子问题

| 子问题类型 | 典型问法 | 对应模型族 |
|---|---|---|
| **分类问题** | "识别……类型"、"判断……属于哪一类" | RF、SVM、GBDT、神经网络 |
| **回归预测** | "预测……的值"、"建立……预测模型" | 线性回归、GBDT、CatBoost、LSTM |
| **公式修正** | "构造修正方程"、"改进……公式" | 非线性最小二乘、curve_fit |
| **因素分析** | "分析……因素影响"、"影响程度" | ANOVA、相关性分析、SHAP |
| **最优化** | "在什么条件下最优"、"最小化/最大化" | LP/NLP、NSGA-II、遗传算法 |

# 第二部分 核心数学模型详解

> 本部分针对数据驱动建模类题目，详解 **7 大类共 20+ 个模型**。每个模型按"原理→公式→功能→用法→案例"五段式说明，确保领导层即使无相关背景也能理解其适用场景。

## 2.1 统计回归模型族

### 2.1.1 线性回归（Linear Regression）

**基本原理**：假设因变量 y 与自变量 X 之间呈线性关系，通过最小化残差平方和求解系数。

**核心公式**：

$$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p + \epsilon$$

参数估计（最小二乘）：

$$\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$$

**功能作用**：
- 解决"已知若干自变量，如何预测连续型因变量"的问题
- 给出每个自变量的影响系数（可解释性强）
- 是其他复杂模型的基准（baseline）

**应用方法**：
1. 确认自变量与因变量的线性关系（散点图）
2. 检验多重共线性（VIF < 10）
3. 拟合模型，检查 R²、调整 R²、F 检验、t 检验
4. 残差分析：正态性（QQ 图）、同方差性、独立性
5. 若不满足假设，对 y 取对数或使用加权回归

**典型案例（2024C 问题二）**：
对磁芯损耗 P 与频率 f、磁通密度 Bm 做对数线性回归：log(P) = log(k) + α·log(f) + β·log(Bm)，可得到 Steinmetz 方程的初值估计，再用于非线性拟合。

**Python 实现**：
```python
from sklearn.linear_model import LinearRegression
import statsmodels.api as sm

# sklearn 方式（适合预测）
model = LinearRegression()
model.fit(X_train, y_train)

# statsmodels 方式（适合统计推断，提供 p 值、F 检验）
X_sm = sm.add_constant(X_train)
result = sm.OLS(y_train, X_sm).fit()
print(result.summary())
```

### 2.1.2 岭回归与 Lasso 回归（Ridge / Lasso）

**基本原理**：在线性回归损失函数中加入 L2（岭）或 L1（Lasso）正则项，防止过拟合，Lasso 还能做特征选择。

**核心公式**：

岭回归：$\min_{\beta} \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 + \lambda \|\boldsymbol{\beta}\|_2^2$

Lasso：$\min_{\beta} \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 + \lambda \|\boldsymbol{\beta}\|_1$

**功能作用**：
- 解决"自变量间高度相关（多重共线性）时普通最小二乘不稳定"的问题
- Lasso 能将不重要变量的系数压缩为 0，实现特征选择
- 适合高维数据（自变量数 > 样本数）

**应用方法**：
1. 数据标准化（必须，否则正则项不公平）
2. 用交叉验证选择 λ（sklearn 中是 alpha）
3. 拟合后查看系数：Lasso 中系数为 0 的变量可剔除

**典型案例**：当特征工程产生 30+ 个特征时，用 Lasso 筛选关键特征。

---

### 2.1.3 多项式回归（Polynomial Regression）

**基本原理**：通过添加自变量的高次项，拟合非线性关系。

**核心公式**：

$$\hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2 + \cdots + \beta_d x^d$$

**功能作用**：拟合曲线关系的数据，是线性回归的直接扩展。

**应用方法**：
1. 选择阶数 d（一般 d ≤ 4，过高会过拟合）
2. 用 `PolynomialFeatures` 生成高次项
3. 配合岭回归防止过拟合

**典型案例（2024C 问题二）**：温度修正方程中的二次项 `(1 + γT + δT²)` 本质是多项式回归。

## 2.2 机器学习模型族

### 2.2.1 随机森林（Random Forest）

**基本原理**：构建多棵决策树，每棵树使用自助采样（bootstrap）的样本和随机选择的特征子集，最终通过投票（分类）或平均（回归）输出结果。

**核心公式**（基尼不纯度，分类）：

$$Gini(t) = 1 - \sum_{k=1}^{K} p_k^2$$

**功能作用**：
- 解决"非线性、高维数据"的分类/回归问题
- 自带特征重要性排序（基于不纯度下降）
- 对缺失值、异常值鲁棒，无需大量调参
- 是数据驱动建模的"瑞士军刀"，几乎所有分类/回归任务都可作为基准

**应用方法**：
1. 直接调用 `RandomForestClassifier` / `RandomForestRegressor`
2. 关键参数：`n_estimators`（树数，100-500）、`max_depth`（深度，或 None）、`min_samples_leaf`（叶节点最小样本数）
3. 用 `feature_importances_` 查看特征重要性
4. 用交叉验证评估泛化性能

**典型案例（2024C 问题一）**：用随机森林对 1024 点磁通密度序列的统计特征做波形分类，5 折 CV 准确率 100%。

**Python 实现**：
```python
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=300, random_state=42, n_jobs=-1)
rf.fit(X_train, y_train)
y_pred = rf.predict(X_test)
importances = rf.feature_importances_
```

### 2.2.2 支持向量机（SVM）

**基本原理**：寻找一个最优超平面，使两类样本之间的间隔（margin）最大化。通过核技巧（kernel trick）处理非线性问题。

**核心公式**（最优超平面）：

$$\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^\top \mathbf{x}_i + b) \geq 1$$

核函数（RBF）：

$$K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2)$$

**功能作用**：
- 解决"小样本、高维、非线性"的分类/回归问题
- 在样本数 < 1000 时常优于深度学习
- 通过核函数灵活处理各种数据分布

**应用方法**：
1. **数据标准化必须做**（SVM 对尺度敏感）
2. 选择核函数：RBF（默认）、linear（线性可分）、poly（多项式）
3. 调参：`C`（惩罚系数，1-100）、`gamma`（核宽度，'scale' 或 'auto'）
4. 用网格搜索 + 交叉验证找最优参数

**典型案例（2024C 问题一）**：SVM 与随机森林集成，软投票提升分类稳健性。

---

### 2.2.3 梯度提升树（XGBoost / LightGBM / CatBoost）

**基本原理**：通过迭代训练弱学习器（决策树），每棵新树拟合前一棵树的残差（负梯度），逐步提升模型性能。XGBoost/LightGBM/CatBoost 是该思想的三大工程实现。

**核心公式**（第 t 轮的损失）：

$$\mathcal{L}^{(t)} = \sum_{i=1}^{n} l(y_i, \hat{y}_i^{(t-1)} + f_t(\mathbf{x}_i)) + \Omega(f_t)$$

其中 $\Omega(f_t) = \gamma T + \frac{1}{2}\lambda \|\mathbf{w}\|^2$ 是正则项。

**三者对比**：

| 特性 | XGBoost | LightGBM | CatBoost |
|---|---|---|---|
| **分裂策略** | 按层生长 | 按叶生长（更高效） | 对称树 |
| **类别特征** | 需手动编码 | 支持原生类别 | **自动处理类别特征** |
| **训练速度** | 中 | **最快** | 中 |
| **精度** | 高 | 高 | **常最高** |
| **适用场景** | 通用 | 大数据、特征工程完善 | 含类别变量、小数据 |

**功能作用**：
- 解决"表格数据"的分类/回归问题，是 Kaggle 竞赛的王者算法
- 精度通常优于随机森林
- 自带特征重要性、缺失值处理

**应用方法**：
1. 三选一即可，推荐 **CatBoost**（处理类别变量最方便，2024C 项目首选）
2. 关键参数：`iterations`（树数，500-2000）、`learning_rate`（0.01-0.1）、`depth`（4-8）
3. **目标变量取对数**：当 y 跨多个数量级时，先 log 变换再拟合
4. 用 early stopping 防止过拟合

**典型案例（2024C 问题四）**：CatBoost 预测磁芯损耗，5 折 CV R²=0.9982，MAPE=2.67%。

**Python 实现**：
```python
from catboost import CatBoostRegressor
model = CatBoostRegressor(
    iterations=1200, depth=8, learning_rate=0.05,
    loss_function="RMSE", random_seed=42, verbose=0,
)
model.fit(X_train, y_train)
# 特征重要性
importances = model.get_feature_importance()
```

### 2.2.4 神经网络（多层感知机 / LSTM / CNN）

**基本原理**：通过多层非线性变换拟合复杂函数关系。LSTM 适合序列数据，CNN 适合图像/空间数据。

**核心公式**（前向传播）：

$$\mathbf{h}^{(l)} = \sigma(\mathbf{W}^{(l)} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)})$$

**功能作用**：
- 解决"超大规模数据、复杂非线性"的预测问题
- LSTM 适合时间序列，CNN 适合图像

**应用方法**：
1. 表格数据优先用 GBDT，**不要轻易用神经网络**（除非样本 > 10万）
2. 若用 NN：标准化输入、BatchNorm、Dropout、early stopping
3. 框架：PyTorch（推荐）或 TensorFlow/Keras

**注意**：研究生数模竞赛中，神经网络往往是"杀鸡用牛刀"，GBDT 已足够。除非题目明确涉及序列/图像，否则不用。

## 2.3 统计分析模型族

### 2.3.1 方差分析（ANOVA）

**基本原理**：通过分解总方差，判断不同组别均值是否有显著差异。

**核心公式**（单因素）：

$$F = \frac{MS_{between}}{MS_{within}} = \frac{SS_{between}/(k-1)}{SS_{within}/(N-k)}$$

效应量：

$$\eta^2 = \frac{SS_{between}}{SS_{total}}$$

**功能作用**：
- 解决"某个分类因素对连续型结果是否有显著影响"的问题
- **效应量 η² 量化影响程度**（而非仅看 p 值）
- 双因素 ANOVA 可分析交互效应

**应用方法**：
1. 因变量需近似正态（**必要时取对数**）
2. 方差齐性检验（Levene 检验）
3. 单因素：`ols('y ~ C(factor)')`；双因素含交互：`ols('y ~ C(f1)*C(f2)')`
4. 报告 F 统计量、p 值、η²

**典型案例（2024C 问题三）**：分析温度、波形、材料对磁芯损耗的影响，η² 排序：波形(0.075) > 材料(0.025) > 温度(0.006)。

**Python 实现**：
```python
import statsmodels.api as sm
from statsmodels.formula.api import ols

model = ols('log_loss ~ C(temperature) * C(waveform)', data=df).fit()
aov_table = sm.stats.anova_lm(model, typ=2)
# 计算效应量
aov_table['eta_sq'] = aov_table['sum_sq'] / aov_table['sum_sq'].sum()
```

### 2.3.2 主成分分析（PCA）

**基本原理**：通过线性变换将高维数据投影到低维空间，保留最大方差方向。

**核心公式**：

$$\max_{\mathbf{w}} \mathbf{w}^\top \mathbf{\Sigma} \mathbf{w} \quad \text{s.t.} \quad \|\mathbf{w}\| = 1$$

**功能作用**：
- 降维（高维数据可视化、去除冗余特征）
- 消除多重共线性

**应用方法**：
1. 数据标准化（必须）
2. 选择主成分数：累计方差贡献率 > 85%
3. 用 `PCA(n_components=2)` 做二维可视化

**典型案例（2024C 可视化）**：将 29 维特征用 PCA 降到 2 维，可视化三种波形的聚类结构。

---

### 2.3.3 相关性分析与假设检验

**基本原理**：检验变量间是否存在统计显著的关联。

**核心方法**：

| 场景 | 方法 |
|---|---|
| 两个连续变量 | Pearson 相关系数 |
| 连续变量 + 分类变量 | t 检验 / ANOVA |
| 两个分类变量 | 卡方检验 |
| 非正态数据 | Spearman 秩相关 / Mann-Whitney U |

**功能作用**：因素筛选、变量关系验证。

## 2.4 优化模型族

### 2.4.1 线性规划与整数规划

**基本原理**：在线性约束下，优化线性目标函数。

**标准形式**：

$$\max \mathbf{c}^\top \mathbf{x} \quad \text{s.t.} \quad \mathbf{A}\mathbf{x} \leq \mathbf{b}, \ \mathbf{x} \geq 0$$

**功能作用**：资源分配、生产计划、运输问题。

**应用方法**：
1. 定义决策变量
2. 写出目标函数与约束
3. 用 `scipy.optimize.linprog` 或 `PuLP` 求解

---

### 2.4.2 非线性规划（NLP）

**基本原理**：目标函数或约束含非线性项。

**核心方法**：
- 无约束：梯度下降、牛顿法
- 有约束：序列二次规划（SQP）、内点法

**Python 实现**：`scipy.optimize.minimize`

**典型案例（2024C 问题二）**：用 `curve_fit` 拟合 Steinmetz 方程 `P = k·f^α·Bm^β`，本质是非线性最小二乘。

### 2.4.3 多目标优化与 NSGA-II

**基本原理**：当存在多个相互冲突的目标时，不存在唯一最优解，而是 Pareto 最优解集。NSGA-II 通过非支配排序 + 拥挤距离维护前沿多样性。

**核心概念**：
- **Pareto 支配**：解 A 支配 B，当且仅当 A 在所有目标上不劣于 B，且至少一个目标严格更优
- **Pareto 前沿**：所有非支配解的集合

**功能作用**：
- 解决"既要……又要……"的多目标冲突问题
- 给出 Pareto 前沿供决策者选择

**应用方法**：
1. 定义目标函数（≥2 个）
2. 定义决策变量及其边界
3. 配置 NSGA-II：种群大小、代数、交叉/变异算子
4. 运行优化，得到 Pareto 前沿
5. 用决策规则（如加权、比值）选最终方案

**典型案例（2024C 问题五）**：双目标优化——min 磁芯损耗 + max 传输磁能(f·Bm)，NSGA-II 得到 200 个 Pareto 解，按"损耗/磁能比"选最佳折中方案。

**Python 实现**：
```python
from pymoo.algorithms.moo.nsga2 import NSGA2
from pymoo.core.problem import ElementwiseProblem
from pymoo.optimize import minimize

class MyProblem(ElementwiseProblem):
    def __init__(self):
        super().__init__(n_var=5, n_obj=2,
                         xl=lower_bounds, xu=upper_bounds)
    def _evaluate(self, x, out, *args, **kwargs):
        out["F"] = np.array([loss(x), -energy(x)])

algorithm = NSGA2(pop_size=200, sampling=FloatRandomSampling(),
                  crossover=SBX(prob=0.9, eta=15),
                  mutation=PM(prob=0.1, eta=20))
res = minimize(MyProblem(), algorithm, ('n_gen', 300), seed=42)
```

### 2.4.4 启发式算法（遗传算法 / 模拟退火 / 粒子群）

**基本原理**：模拟自然进化或物理过程，在解空间中搜索最优解。

| 算法 | 模拟对象 | 适用场景 |
|---|---|---|
| **遗传算法（GA）** | 生物进化（选择/交叉/变异） | 组合优化、复杂非凸问题 |
| **模拟退火（SA）** | 金属退火过程 | 全局优化、避免局部最优 |
| **粒子群（PSO）** | 鸟群觅食 | 连续优化、收敛快 |

**功能作用**：当问题不可微或解空间巨大时，传统数学规划失效，启发式算法是兜底方案。

## 2.5 评价决策模型族

### 2.5.1 层次分析法（AHP）

**基本原理**：将复杂决策问题分解为目标层、准则层、方案层，通过两两比较构造判断矩阵，计算权重。

**核心公式**（判断矩阵的最大特征值对应特征向量归一化即为权重）：

$$\mathbf{A}\mathbf{w} = \lambda_{max} \mathbf{w}$$

一致性检验：$CR = \frac{CI}{RI} < 0.1$，其中 $CI = \frac{\lambda_{max} - n}{n-1}$

**功能作用**：主观权重确定，适合定性指标较多的评价问题。

---

### 2.5.2 熵权法 + TOPSIS

**基本原理**：熵权法根据指标值的离散程度客观赋权；TOPSIS 根据方案与理想解/负理想解的距离排序。

**功能作用**：客观评价、方案排序。

**应用方法**：
1. 数据标准化（正向化 + 归一化）
2. 熵权法计算权重
3. 计算加权矩阵
4. 计算各方案与理想解的距离
5. 按相对贴近度排序

---

## 2.6 特征工程技术

> 特征工程是数据驱动建模的"第二模型"，往往比换模型更能提升性能。

### 2.6.1 时域特征提取

| 特征 | 公式 | 用途 |
|---|---|---|
| 均值 | $\bar{x} = \frac{1}{n}\sum x_i$ | 中心趋势 |
| 标准差 | $\sigma = \sqrt{\frac{1}{n}\sum(x_i-\bar{x})^2}$ | 离散程度 |
| 峰度 | $\kappa = \frac{1}{n}\sum\left(\frac{x_i-\bar{x}}{\sigma}\right)^4 - 3$ | 分布尖峰程度 |
| 偏度 | $s = \frac{1}{n}\sum\left(\frac{x_i-\bar{x}}{\sigma}\right)^3$ | 分布不对称性 |
| 峰值因子 | $C = \frac{\max|x|}{\text{RMS}}$ | 信号冲击性 |
| 波形因子 | $S = \frac{\text{RMS}}{\bar{|x|}}$ | 信号形状 |

### 2.6.2 频域特征提取

| 特征 | 说明 |
|---|---|
| FFT 主频幅值 | 信号的主要频率成分 |
| 谱熵 | $H = -\sum p_i \log p_i$，频谱的复杂度 |
| 谱质心 | $\sum f_i \cdot |X_i| / \sum |X_i|$，频谱重心位置 |

### 2.6.3 形状特征（针对波形分类）

这是 2024C 项目的创新点，专门设计用于区分正弦/三角/梯形波：
- **平台段比例**：`|diff| < 0.05·peak` 的样本占比 → 区分梯形波
- **最大斜率**：区分三角波（最大）与正弦波（中等）
- **斜率峰度**：梯形波斜率分布双峰

## 2.7 模型评估指标体系

### 分类指标

| 指标 | 公式 | 适用场景 |
|---|---|---|
| 准确率 | $(TP+TN)/(TP+TN+FP+FN)$ | 类别均衡 |
| 精确率 | $TP/(TP+FP)$ | 关注误报 |
| 召回率 | $TP/(TP+FN)$ | 关注漏报 |
| F1 | $2·P·R/(P+R)$ | 类别不均衡 |
| 混淆矩阵 | — | 多分类可视化 |

### 回归指标

| 指标 | 公式 | 说明 |
|---|---|---|
| R² | $1 - \frac{SS_{res}}{SS_{tot}}$ | 决定系数，越接近 1 越好 |
| MAE | $\frac{1}{n}\sum|y_i-\hat{y}_i|$ | 平均绝对误差 |
| MAPE | $\frac{100\%}{n}\sum\frac{|y_i-\hat{y}_i|}{y_i}$ | **百分比误差，最常用** |
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i-\hat{y}_i)^2}$ | 均方根误差 |

**关键经验**：
- 当 y 跨多个数量级时，**必须看 MAPE 而非 R²**
- **log 变换后训练**，预测时 exp 还原，是处理跨数量级 y 的标准做法

## 3.2 各阶段关键任务详解

### 阶段 0：读题与定位

**关键任务**：
1. **5 分钟速读**：先看问题要求，再看背景（带着问题读背景更高效）
2. **识别题目类型**：根据第一部分的 5 大类特征判定
3. **提取子问题**：数模题通常 4-6 问，逐问列出"要做什么 + 输出什么"
4. **识别约束**：填表格式、保留小数位数、指定样本号等
5. **时间分配**：4 天 = 96 小时，建议
   - 读题+EDA：10%
   - 建模+训练：40%
   - 论文写作：30%
   - 检查修改：20%

**输出物**：一张"子问题-方法-输出"三列表格。

**典型案例（2024C）**：

| 子问题 | 任务 | 方法 | 输出 |
|---|---|---|---|
| Q1 | 波形分类 | RF+SVM+GBDT 集成 | 附件四第 2 列 |
| Q2 | SE 温度修正 | 非线性最小二乘 | R²/MAPE 对比表 |
| Q3 | 因素分析 | ANOVA + η² | 影响排序表 |

| Q5 | 最优化 | NSGA-II | Pareto 前沿 + 决策方案 |

---

### 阶段 1：数据探索（EDA）

**关键任务**：
1. **数据加载**：统一用 pandas 读取，保存为 parquet 格式（比 CSV 快 10 倍）
2. **完整性检查**：样本数、字段数、缺失值、数据类型
3. **描述统计**：均值、标准差、分位数、值域
4. **可视化**：
   - 分布图（直方图 + KDE）
   - 类别平衡性（柱状图）
   - 相关性热力图
   - 散点图矩阵（关键变量两两关系）
5. **异常值检测**：箱线图、3σ 准则、IQR 准则

**代码模板**：
```python
# 数据概览
print(df.shape)
print(df.dtypes)
print(df.describe())
print(df.isna().sum())

# 分布可视化
fig, axes = plt.subplots(2, 3, figsize=(15, 9))
# ... 各列直方图
```

**关键检查点**：
- ✅ 目标变量是否跨多个数量级？→ 考虑 log 变换
- ✅ 类别是否不均衡？→ 考虑分层采样 / SMOTE
- ✅ 是否有类别变量？→ one-hot 编码或用 CatBoost

---

### 阶段 2：特征工程

**关键任务**：
1. **特征提取**：从原始数据中构造新特征
   - 时域：统计量（均值、方差、峰度、偏度、峰值因子）
   - 频域：FFT 主频、谱熵、谱质心
   - 形状特征：针对特定问题设计（如平台段比例）
2. **特征变换**：
   - log 变换：处理长尾分布
   - 标准化：Z-score 或 Min-Max
   - one-hot：类别变量编码
3. **特征选择**：
   - 过滤法：相关系数、方差阈值
   - 包装法：递归特征消除（RFE）
   - 嵌入法：Lasso、树模型重要性
4. **特征一致性**：训练与预测时特征顺序必须一致（用统一函数构造）

**关键原则**：
- 特征工程 > 模型选择（好的特征 + 简单模型 > 差的特征 + 复杂模型）
- 物理意义优先（结合领域知识设计的特征往往最有效）
- 先少后多（先基线特征，再逐步添加）

---

### 阶段 3：模型选择与设计

**关键任务**：
1. **列出候选模型**（≥3 个）：根据问题类型选择
   - 分类：RF、SVM、GBDT
   - 回归：线性回归、GBDT、CatBoost
   - 优化：LP、NLP、NSGA-II
2. **设计对比实验**：
   - 同一数据划分
   - 同一评估指标
   - 同一随机种子
3. **确定评估指标**：
   - 分类：准确率、F1、混淆矩阵
   - 回归：R²、MAPE、RMSE
4. **设计消融实验**（可选）：去掉某些特征看性能变化

**决策树**：
```
是否为分类问题？
├─ 是 → 数据量 < 1000？
│       ├─ 是 → SVM / RF
│       └─ 否 → GBDT / RF
└─ 否 → 是否为回归问题？
        ├─ 是 → 关系是否线性？
        │       ├─ 是 → 线性回归 / 岭回归
        │       └─ 否 → CatBoost / LightGBM
        └─ 否 → 是否为优化问题？
                ├─ 是 → 线性？ → LP
                │       非线性？ → NLP / 启发式
                │       多目标？ → NSGA-II
                └─ 否 → 评价问题？ → AHP / TOPSIS
```

---

### 阶段 4：模型构建与训练

**关键任务**：
1. **数据划分**：
   - 训练集 / 验证集 = 8:2（随机种子固定）
   - 或 K 折交叉验证（K=5 或 10）
2. **多模型训练**：每个模型独立训练，记录验证集性能
3. **超参数调优**：
   - 网格搜索（GridSearchCV）：小参数空间
   - 随机搜索（RandomizedSearchCV）：大参数空间
   - 贝叶斯优化（Optuna）：高效
4. **交叉验证**：5 折或 10 折，报告均值±标准差
5. **集成学习**（可选）：投票、Stacking、Boosting

**关键检查点**：
- ✅ 是否过拟合？（训练集 R² >> 验证集 R²）
- ✅ 是否欠拟合？（两者 R² 都低）
- ✅ 随机种子是否固定？（保证可复现）

# 第五部分 多模型训练与比较策略

## 5.1 为什么必须多模型比较？

### 5.1.1 没有免费午餐定理（No Free Lunch Theorem）

> **定理**：在所有可能的问题上，没有任何一个算法的平均表现优于其他算法。

**含义**：不存在"万能模型"。某个模型在 A 数据集上最优，在 B 数据集上可能最差。**必须通过实验对比才能确定当前问题的最优模型**。

### 5.1.2 偏差-方差权衡（Bias-Variance Tradeoff）

| 模型复杂度 | 偏差 | 方差 | 风险 |
|---|---|---|---|
| 线性回归 | 高（欠拟合） | 低 | 无法捕捉非线性 |
| 决策树（深） | 低 | 高（过拟合） | 对训练集过拟合 |
| 随机森林 | 中 | 中 | 平衡较好 |
| GBDT | 低 | 中 | 常为最优 |
| 神经网络 | 极低 | 极高 | 需大数据 |

**含义**：不同模型在偏差-方差谱上的位置不同，**多模型对比能找到当前数据规模下的最优点**。

### 5.1.3 论文说服力

- 评委喜欢看到"我尝试了多种模型并对比，最终选择 X"——这体现严谨性
- 单一模型 = "为什么不用别的？" 的质疑无法回答
- 多模型对比表是论文的加分项

### 5.1.4 2024C 案例验证

| 问题 | 模型对比 | 最优 | 提升幅度 |
|---|---|---|---|
| Q1 | RF vs SVM vs GBDT | 三者均 100% | 集成确保稳健 |
| Q2 | 原始SE vs 线性 vs 二次 vs 指数 | 二次修正 | MAPE 降 36.8% |
| Q4 | CatBoost vs LightGBM vs XGBoost vs RF | CatBoost | R² 0.998 vs 0.988 |

## 5.2 何时需要多模型比较？

### 必须做的情况

✅ **分类/回归任务**：至少对比 3 个模型（如 RF + SVM + GBDT）
✅ **公式修正**：至少对比 2-3 种修正形式
✅ **优化问题**：至少对比 2 种算法（如 NSGA-II + 加权法）
✅ **评价问题**：至少对比 2 种赋权方法（如 AHP + 熵权法）

### 可不做的情况

❌ **数据探索阶段**的初步分析
❌ **明确的物理机理**已限定模型形式（如已知是线性关系）
❌ **时间极度紧张**时（先保证有结果，再考虑对比）

## 5.3 多模型比较的实施策略

### 5.3.1 实验设计原则

1. **控制变量**：所有模型使用相同的数据划分、随机种子、评估指标
2. **公平评估**：
   - 同一交叉验证折数
   - 同一超参数搜索预算
   - 同一硬件环境
3. **多指标评估**：不要只看一个指标（如只看 R² 会忽略极端误差）

### 5.3.2 标准对比实验代码模板

```python
from sklearn.model_selection import KFold
from sklearn.metrics import r2_score, mean_absolute_percentage_error
import pandas as pd
import numpy as np

def compare_models(models: dict, X, y, n_splits=5):
    """多模型对比实验。
    
    Args:
        models: {"模型名": 模型实例} 字典
        X, y: 特征与目标
        n_splits: 交叉验证折数
    Returns:
        DataFrame，每行一个模型，列为各指标的均值±标准差
    """
    kf = KFold(n_splits=n_splits, shuffle=True, random_state=42)
    results = []
    
    for name, model in models.items():
        r2_scores, mape_scores = [], []
        for tr_idx, va_idx in kf.split(X):
            # 克隆模型（避免状态污染）
            from sklearn.base import clone
            m = clone(model) if hasattr(model, 'get_params') else model.__class__(**model.get_params())
            m.fit(X[tr_idx], y[tr_idx])
            y_pred = m.predict(X[va_idx])
            r2_scores.append(r2_score(y[va_idx], y_pred))
            mape_scores.append(mean_absolute_percentage_error(y[va_idx], y_pred))
        
        results.append({
            "model": name,
            "R2_mean": np.mean(r2_scores),
            "R2_std": np.std(r2_scores),
            "MAPE_mean": np.mean(mape_scores) * 100,
            "MAPE_std": np.std(mape_scores) * 100,
        })
        print(f"  {name:15s}  R²={np.mean(r2_scores):.4f}  MAPE={np.mean(mape_scores)*100:.2f}%")
    
    return pd.DataFrame(results).sort_values("R2_mean", ascending=False)

# 使用示例
models = {
    "CatBoost": CatBoostRegressor(iterations=1200, depth=8, learning_rate=0.05, verbose=0),
    "LightGBM": LGBMRegressor(n_estimators=1200, learning_rate=0.05),
    "XGBoost": XGBRegressor(n_estimators=1200, max_depth=8, learning_rate=0.05),
    "RandomForest": RandomForestRegressor(n_estimators=400, n_jobs=-1),
}
cv_results = compare_models(models, X, y)
```

### 5.3.3 模型选择决策表

| 场景 | 推荐对比模型 | 选择依据 |
|---|---|---|
| **分类（小数据 < 1000）** | SVM + RF + GBDT | 看准确率 + F1 |
| **分类（大数据 > 1000）** | RF + LightGBM + CatBoost | 看准确率 + 推理速度 |
| **回归（线性关系）** | 线性回归 + 岭回归 + Lasso | 看 R² + 系数显著性 |
| **回归（非线性）** | RF + CatBoost + LightGBM | 看 R² + MAPE |
| **回归（跨数量级 y）** | 同上 + 对 y 取 log | 看 MAPE（非 R²）|
| **时间序列** | ARIMA + LSTM + Prophet | 看 RMSE + MAPE |
| **多目标优化** | NSGA-II + MOEA/D + 加权法 | 看 Pareto 前沿质量 |
| **评价排序** | AHP + 熵权法 + 灰色关联 | 看排序一致性 |

## 5.4 模型评估指标体系

### 5.4.1 分类指标选择指南

```
类别是否均衡？
├─ 均衡 → 准确率 + 混淆矩阵
└─ 不均衡 → F1 + ROC-AUC + PR-AUC
```

### 5.4.2 回归指标选择指南

```
y 是否跨多个数量级？
├─ 是 → MAPE（百分比误差，最关键）+ 对数坐标 R²
└─ 否 → R² + RMSE + MAE
```

### 5.4.3 优化问题评估

| 指标 | 说明 |
|---|---|
| **Pareto 前沿规模** | 非支配解数量 |
| **超体积（HV）** | 前沿与参考点围成的体积，越大越好 |
| **收敛性** | 前沿随代数的变化 |
| **多样性** | 前沿解的分布均匀性 |

## 5.5 模型集成策略

当单个模型表现不足时，可考虑集成：

| 集成方法 | 适用场景 | 实现难度 |
|---|---|---|
| **投票（Voting）** | 分类，多个强模型 | 低 |
| **平均（Averaging）** | 回归，多个强模型 | 低 |
| **Stacking** | 用元模型学习如何组合 | 中 |
| **Boosting** | 弱模型串联提升 | 中（直接用 GBDT） |
| **Bagging** | 降低方差 | 低（直接用 RF） |

**2024C 案例**：Q1 用 RF + SVM + GBDT 软投票集成，准确率 100%。

## 5.6 模型选择最终建议

### 5.6.1 数据驱动建模的"默认配置"

当不确定用什么模型时，按以下顺序尝试：

1. **分类**：随机森林（基线）→ CatBoost（进阶）→ 集成（终极）
2. **回归**：线性回归（基线）→ CatBoost（进阶）→ 集成（终极）
3. **优化**：scipy.optimize（小规模）→ pymoo NSGA-II（多目标）

### 5.6.2 模型选择的"奥卡姆剃刀"

> 在性能相近的情况下，选择更简单的模型。

- CatBoost R²=0.998 vs 神经网络 R²=0.999 → **选 CatBoost**（可解释、训练快）
- 线性回归 R²=0.95 vs GBDT R²=0.96 → **看任务需求**（需要可解释性选线性）
