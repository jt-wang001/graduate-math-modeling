# 成员1：建模负责人学习手册

## 一、角色定位与主要任务

建模负责人的核心任务，是把赛题中的自然语言问题转化为一套能够计算、验证并写入论文的数学模型，同时保证三个人始终围绕同一目标协作。

这个角色不是“负责想一个高级算法”，也不是简单分派任务。需要对选题、建模路线、模型假设、评价指标、进度和最终提交负责。

### 1. 赛前任务

- 了解中国研究生数学建模竞赛的题型、论文结构、提交方式和时间压力；
- 掌握预测、评价、优化、调度等常见模型的适用场景；
- 带领团队完成至少两次完整模拟赛；
- 建立选题评分表、问题拆解表、模型规格卡、风险登记表；
- 确认每个人的任务接口和交付时间；
- 负责保存赛事账号、队伍编号、官方通知与提交要求。

### 2. 比赛期间任务

- 组织三人阅读 A—F 题，主持选题并限定选题时间；
- 将选中题目的每一问拆为输入、输出、变量、约束、指标和交付物；
- 提出基线方案、主方案和失败时的降级方案；
- 明确模型假设、数学符号、目标函数和约束；
- 把模型写成代码负责人可以直接实现的规格；
- 检查实验结果是否真正回答题目；
- 安排模型对比、误差分析、敏感性和稳健性检验；
- 每隔约6小时确认进度、风险和下一阶段唯一核心交付；
- 控制方案范围，避免比赛后期反复更换模型；
- 最后审核全文逻辑，主持逐问模拟答辩；
- 负责最终PDF冻结、MD5和上传状态确认。

### 3. 必须交付的成果

- 选题评分表；
- 逐问拆解表；
- 技术路线图；
- 模型假设和符号表初稿；
- 每一问的模型规格卡；
- 基线、主模型和改进模型对比方案；
- 敏感性、稳健性或消融实验方案；
- 风险登记表与阶段决策记录；
- 最终模型逻辑审查表。

## 二、完整工作流程

### 阶段1：赛题初读与筛选

1. 快速浏览全部题目的背景、问题数量、附件类型和输出要求；
2. 为每道候选题标记主要类型：预测、分类、评价、优化、仿真、图像或信号；
3. 要求代码负责人试读附件，判断格式、数据量和算力风险；
4. 要求论文负责人判断题目能否形成清楚的证据链；
5. 按“题意清晰度、数据可用性、技术匹配度、闭环可能性、论文表现力”评分；
6. 原则上在开赛后3—5小时内完成选题。

#### 选题阶段完成标准

- 三人都能用两分钟说清候选题每一问要求；
- 附件至少成功读取一个样例；
- 已明确主要评价指标；
- 已排除无法读取、算力不足或领域门槛过高的题；
- 最终选择有书面评分依据，而不是凭感觉。

### 阶段2：逐问拆解

每一问必须填写以下内容：

| 项目 | 要回答的问题 |
|---|---|
| 任务目标 | 这一问究竟要求预测、解释、评价还是决策？ |
| 输入 | 使用哪些附件、字段和前一问结果？ |
| 输出 | 最终要给数值、类别、方案、排序还是图？ |
| 变量与参数 | 哪些量由模型决定，哪些量由数据给定？ |
| 约束 | 结果必须满足哪些物理、业务或逻辑条件？ |
| 指标 | 如何判断结果好坏？ |
| 方法 | 最低基线、主模型和可能改进分别是什么？ |
| 验证 | 如何证明结果可信？ |
| 论文交付 | 需要哪些公式、表格、图片和结论？ |

### 阶段3：建立基线方案

- 预测题先做均值、线性回归或简单树模型；
- 分类题先做多数类、逻辑回归或简单决策树；
- 优化题先做人工规则、贪心或小规模精确模型；
- 评价题先做等权或简单标准化评价；
- 基线必须可运行、可解释，并作为后续改进的参照。

不要跳过基线直接上复杂模型。没有基线就无法证明复杂方法是否真正带来提升。

### 阶段4：主模型设计

1. 明确模型假设及其合理性；
2. 定义符号、单位和下标；
3. 写出模型输入、输出、公式、目标函数和约束；
4. 指定求解算法和关键参数；
5. 指定数据划分与评价指标；
6. 估计模型规模、运行时间和失败风险；
7. 将上述内容交给代码负责人确认可实现性。

### 阶段5：结果审核与模型改进

- 检查指标是否与题目目标一致；
- 检查训练集与测试集是否混用；
- 检查优化结果是否满足全部约束；
- 检查模型结论是否符合常识、单位和边界；
- 与基线模型公平比较；
- 只选择能够用实验说明价值的改进；
- 对异常结果先排查数据和代码，再讨论理论解释。

### 阶段6：验证与论文闭环

至少完成以下一种验证，推荐完成两种：

- 交叉验证或时间滚动验证；
- 不同模型的公平对比；
- 消融实验；
- 参数敏感性分析；
- 数据扰动或不同情景下的稳健性分析；
- 优化方案的逐条约束校验；
- 极端条件和边界条件测试。

### 阶段7：最终收口

- 停止无必要的新模型尝试；
- 逐问检查是否都有明确答案；
- 检查摘要和结论是否包含关键数字；
- 检查论文中的模型名称、符号、指标和结果是否一致；
- 三人进行一次15分钟无稿答辩；
- 提前冻结PDF，生成MD5后禁止再改文件。

## 三、需要学习的知识、资源与达标标准

## 1. 数学建模基本流程

### 需要学习

- 从现实问题到数学问题的抽象过程；
- 模型假设、变量、参数、目标、约束和评价指标；
- 模型求解、检验、评价与推广；
- 一道题多个小问之间的依赖关系；
- 基线模型、主模型和改进模型的区别。

### 学习资源

- [数学建模导论：基于Python语言（B站）](https://www.bilibili.com/video/BV12W4y1C7Tr/)
- [Python数学建模与分析课程（B站）](https://www.bilibili.com/video/BV1Hh4y1w7fZ/)
- [研究生数学建模往届资料与论文](https://github.com/zhanwen/MathModel)

### 达标标准

- 随机抽取一道往届题，30分钟内完成逐问拆解；
- 能准确区分预测、解释、评价和优化任务；
- 能为每一问写出输入、输出、约束和指标；
- 能画出一页完整技术路线图；
- 能提出一个简单基线和一个合理改进方向。

## 2. 概率统计与数据分析基础

### 需要学习

- 均值、中位数、方差、分位数、偏度和异常值；
- 概率分布、抽样、置信区间和假设检验；
- 相关分析与因果关系的区别；
- 线性回归的基本假设；
- 残差分析、多重共线性和异方差；
- 缺失值和异常值处理的影响；
- 数据泄漏和过拟合。

### 学习资源

- [statsmodels用户指南](https://www.statsmodels.org/stable/user-guide.html)
- [scikit-learn模型选择与评估](https://scikit-learn.org/stable/model_selection.html)
- [pandas入门教程](https://pandas.pydata.org/docs/getting_started/intro_tutorials/)

### 达标标准

- 能独立解读一份描述统计表和相关热图；
- 能说明相关性为什么不能直接证明因果；
- 能解释训练集、验证集和测试集的作用；
- 能识别至少三种常见数据泄漏；
- 能根据残差图指出模型可能存在的问题；
- 能选择适合回归和分类任务的评价指标。

## 3. 回归与预测模型

### 需要学习

- 线性回归、岭回归和Lasso；
- 决策树、随机森林和梯度提升树；
- 时间序列的趋势、周期、滞后和滚动特征；
- 训练验证划分、K折交叉验证和时间滚动验证；
- MAE、MSE、RMSE、MAPE和R²；
- 特征重要性和模型解释。

### 学习资源

- [scikit-learn监督学习教程](https://scikit-learn.org/stable/supervised_learning.html)
- [scikit-learn交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html)
- [statsmodels时间序列分析](https://www.statsmodels.org/stable/tsa.html)

### 达标标准

- 使用2024年C题数据完成至少三种回归模型；
- 所有模型使用相同数据划分进行公平比较；
- 能解释MAE、RMSE和R²分别表达什么；
- 能输出逐折指标的均值与标准差；
- 能完成残差图和误差分组分析；
- 能说明为什么最终选择某个模型，而不是只看一个最高指标。

## 4. 分类与诊断模型

### 需要学习

- 逻辑回归、决策树、随机森林和支持向量机；
- 类别不平衡、类别权重和重采样；
- 混淆矩阵、准确率、精确率、召回率、F1和AUC；
- 分类阈值与误判成本；
- 特征选择和可解释性。

### 学习资源

- [scikit-learn分类算法](https://scikit-learn.org/stable/supervised_learning.html)
- [scikit-learn分类指标](https://scikit-learn.org/stable/modules/model_evaluation.html#classification-metrics)
- [2025年E题：高速列车轴承智能故障诊断](../2025年中国研究生数学建模竞赛赛题/E题：高速列车轴承智能故障诊断问题.pdf)

### 达标标准

- 能解释混淆矩阵中四类结果；
- 面对类别不平衡时不会只使用准确率；
- 能根据任务代价选择召回率、精确率或F1；
- 能完成至少三种分类模型的公平对比；
- 能分析模型最容易错在哪些样本上。

## 5. 运筹优化与调度

### 需要学习

- 决策变量、目标函数和约束；
- 线性规划、整数规划和混合整数规划；
- 0-1变量与逻辑条件；
- 指派、排班、装箱、网络流和路径问题；
- 多目标优化、权重法、ε约束和Pareto思想；
- 贪心、局部搜索、遗传算法和模拟退火；
- 最优解、可行解、上下界和最优间隙。

### 学习资源

- [Google OR-Tools优化教程](https://developers.google.com/optimization)
- [PuLP线性与整数规划文档](https://coin-or.github.io/pulp/)
- [Pyomo建模文档](https://pyomo.readthedocs.io/)
- [SciPy optimize文档](https://docs.scipy.org/doc/scipy/tutorial/optimize.html)

### 达标标准

- 能把一段业务规则写成变量、目标和约束；
- 能独立建立一个小型指派或排班模型；
- 能解释0-1变量的作用；
- 能检查求解器返回状态和最优间隙；
- 能逐条验证输出方案满足全部约束；
- 使用启发式算法时，会进行多次运行并报告稳定性；
- 不把未知全局最优性的结果写成“最优解”。

## 6. 模型验证、敏感性与稳健性

### 需要学习

- 基线对比和公平实验；
- 交叉验证和滚动验证；
- 消融实验；
- 参数敏感性分析；
- 数据扰动、噪声和不同情景测试；
- 极端值、边界条件和约束校验。

### 学习资源

- [scikit-learn模型选择与验证](https://scikit-learn.org/stable/model_selection.html)
- [scikit-learn学习曲线示例](https://scikit-learn.org/stable/modules/learning_curve.html)
- [往届数学建模论文资料库](https://github.com/zhanwen/MathModel)

### 达标标准

- 每个主模型都有一个基线；
- 每项改进都有对应的对照实验；
- 能选择至少三个关键参数做敏感性分析；
- 能说明模型在哪些条件下会失效；
- 能区分“模型表现稳定”和“模型一定正确”。

## 7. 队长项目管理

### 需要学习

- 限时选题和证据化决策；
- 任务拆分、里程碑和关键路径；
- 风险登记和应急预案；
- 版本冻结与降级策略；
- 短会组织和冲突处理；
- MD5与最终提交管理。

### 学习资源

- [中国研究生数学建模竞赛官方通知](https://cpipc.acge.org.cn/cw/contestNews/list/4/3)

### 达标标准

- 能组织一次3小时限时选题演练；
- 能为完整比赛制定6小时粒度的里程碑；
- 风险表中每个风险都有触发信号和应急措施；
- 任何时刻都能说清当前模型、数据和论文版本；
- 能在截止前至少3小时冻结最终PDF；
- 能独立完成MD5、上传和提交状态核查。

## 四、建议训练题顺序

1. 2024年C题：练习数据分析、回归、影响因素和优化；
2. 2022年B题：练习组合优化；
3. 2022年C题：练习生产调度和复杂约束；
4. 2023年C题：练习评价、公平性和匹配；
5. 2021年F题：练习大规模机组排班；
6. 2025年E题：练习分类、诊断和泛化。

## 五、个人最终验收

达到以下标准，才算基本具备参赛能力：

- 30分钟内完成一道题的逐问拆解；
- 5小时内带队完成选题；
- 能提出基线、主模型、改进和验证方案；
- 能写出清晰的变量、目标函数和约束；
- 能识别数据泄漏、过拟合和不可验证结论；
- 能审查代码结果是否满足模型要求；
- 能主持一次完整72—96小时模拟赛；
- 能无稿解释全文模型、结果、限制和创新点；
- 能安全完成最终PDF、MD5和上传。
