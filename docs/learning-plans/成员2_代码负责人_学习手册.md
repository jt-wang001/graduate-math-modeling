# 成员2：代码负责人学习手册
##测试

## 一、角色定位与主要任务

代码负责人负责把建模方案实现为可靠、可复现的程序，并保证论文中的每个关键数字、表格和图片都有明确来源。

这个角色的目标不是写最多代码，而是在最短时间内得到正确的基线，逐步改进，并让整个实验随时可以复现和回退。

### 1. 赛前任务

- 配置Python、Jupyter或VS Code环境；
- 掌握CSV、Excel、MAT、TXT等常见附件读取方式；
- 建立团队代码目录、命名规范和实验登记表；
- 准备数据审计、回归、分类、优化和制图模板；
- 完成至少两道数据题和一道优化题；
- 测试备份、环境导出和另一台电脑复现流程。

### 2. 比赛期间任务

- 在选题阶段快速读取候选题附件；
- 报告文件类型、数据量、缺失、异常和算力风险；
- 建立数据字典并保护原始数据；
- 按建模规格先实现最小可运行基线；
- 完成预处理、特征工程、训练、验证和评价；
- 记录每次实验的数据版本、参数、随机种子和指标；
- 生成论文所需的高质量图表和结果表；
- 对优化结果编写独立约束校验器；
- 在提交前重新运行最终入口；
- 保证论文每个关键数字都能追溯到脚本和输出文件。

### 3. 必须交付的成果

- `README.md`和环境依赖文件；
- 数据字典与数据审计报告；
- 数据预处理脚本；
- 基线模型和主模型代码；
- 实验登记表；
- 最终结果CSV；
- 论文图片及生成脚本；
- 优化方案约束校验结果；
- 一键生成核心结果的入口脚本。

## 二、完整工作流程

### 阶段1：选题阶段的数据风险检查

对每道候选题做最小读取：

1. 文件能否正常解压和打开；
2. 文件数量、总大小和单文件大小；
3. 字段、行列数和数据类型；
4. 是否包含视频、遥感、三维或专用格式；
5. 是否需要GPU或长时间训练；
6. 是否存在严重缺失、乱码或字段说明不足；
7. 是否能在现有电脑上完成最小实验。

### 阶段2：数据审计

建立只读原始数据目录，输出以下内容：

- 文件清单和数据规模；
- 字段名称、类型、单位和含义；
- 主键或样本唯一标识；
- 缺失值数量与比例；
- 重复记录；
- 异常值和非法取值；
- 时间范围、采样间隔和排序；
- 类别分布；
- 训练集、测试集或答案表之间的关系；
- 拟采用的处理策略及理由。

### 阶段3：建立基线

- 数据能读取后立刻保存一个可运行版本；
- 先使用简单预处理和简单模型；
- 输出最少但完整的评价指标；
- 固定数据划分和随机种子；
- 将基线结果写入实验登记表；
- 确保即使后续复杂模型失败，也有可写入论文的结果。

### 阶段4：主模型和实验

1. 根据模型规格实现预处理流水线；
2. 严格隔离训练、验证和测试数据；
3. 在相同划分上比较模型；
4. 每次只改变一个明确因素；
5. 记录数据版本、特征、模型、参数、种子、指标和运行时间；
6. 将结果保存为CSV或JSON，避免只显示在Notebook中；
7. 发现异常先检查数据索引、单位、目标列和划分。

### 阶段5：验证和误差分析

- 输出逐折指标、均值和标准差；
- 绘制预测值与真实值、残差或混淆矩阵；
- 按类别、区间、场景或时间分析错误；
- 检查模型是否只在某类样本上表现良好；
- 对关键参数做敏感性实验；
- 对优化结果逐条检查约束并重新计算目标值。

### 阶段6：图表和论文交付

每个图表需登记：

- 图号和要表达的结论；
- 使用的数据文件；
- 生成脚本；
- 关键参数；
- 输出尺寸和DPI；
- 论文对应章节；
- 是否经过论文负责人复核。

### 阶段7：最终复现

- 在干净环境或重启后的电脑运行最终入口；
- 确保没有依赖Notebook隐藏变量；
- 确保路径使用相对路径；
- 核对所有图表、结果表和论文数字；
- 导出依赖版本；
- 备份原始数据、代码和最终输出到两个位置。

- `pathlib`与相对路径；
- 虚拟环境和包版本；
- Jupyter Notebook与Python脚本的区别；
- 随机种子和可复现性。

### 学习资源

- [Python官方中文教程](https://docs.python.org/zh-cn/3/tutorial/)

### 达标标准

- 能独立写函数读取、处理并保存数据；
- 能使用异常处理给出清楚的错误信息；
- 代码不包含个人电脑绝对路径；
- 能导出并重建Python环境；

- 筛选、排序、分组、聚合、连接和透视；
- 缺失、重复、类型转换和时间字段；
- 宽表与长表转换；
- 数据字典和审计报告。

### 学习资源

- [NumPy用户指南](https://numpy.org/doc/stable/user/)
- [pandas入门教程](https://pandas.pydata.org/docs/getting_started/intro_tutorials/)
- [Python数据分析三件套视频](https://www.bilibili.com/video/BV1yi4y147A2/)

### 达标标准

- 一小时内完成普通Excel/CSV的初步审计；
- 能正确合并两个以上数据表并验证行数；
- 能发现主键重复、数据类型错误和时间错序；
- 能输出字段类型、缺失率、唯一值数和基本统计；
- 原始数据始终只读，处理结果由脚本生成；
- 能处理中文编码和日期格式问题。

### 需要学习

- 缺失值插补；
- 异常值识别与处理；
- 类别编码；
- 标准化与归一化；
- 特征筛选；
- `Pipeline`和`ColumnTransformer`；
- 训练、验证、测试隔离；
- 时间序列和分组数据划分。

### 学习资源

- [scikit-learn预处理](https://scikit-learn.org/stable/modules/preprocessing.html)
- [Pipeline官方文档](https://scikit-learn.org/stable/modules/compose.html)

- 能将缩放、插补和模型放入同一Pipeline；
- 标准化参数只在训练数据上学习；

- 同一对象的多条记录不会跨训练集和测试集；

## 5. 回归、分类与模型评估

### 需要学习

- 线性回归、岭回归和Lasso；
- 逻辑回归、决策树、随机森林和梯度提升；
- 支持向量机；
- K折、分组和时间序列验证；
- 网格搜索和随机搜索；
- 回归、分类指标；
- 特征重要性和错误样本分析。

### 学习资源

- [scikit-learn监督学习](https://scikit-learn.org/stable/supervised_learning.html)
- [scikit-learn模型选择](https://scikit-learn.org/stable/model_selection.html)
- [scikit-learn模型评估](https://scikit-learn.org/stable/modules/model_evaluation.html)

### 达标标准

- 能为同一数据实现至少三种模型；
- 所有模型采用相同划分和评价指标；
- 输出逐折指标、均值和标准差；
- 调参过程不接触最终测试集；
- 分类不平衡时不会只报告准确率；
- 能输出误差最大的样本并分析原因；
- 能说明复杂模型是否值得采用。

## 6. 时间序列与信号特征

### 需要学习

- 时间排序、采样频率和缺失时间点；
- 滞后、滚动统计、趋势和周期；
- 滚动验证；
- 信号的均值、方差、峰值、峭度、频谱等特征；
- 时域、频域与窗口切分；
- 同一设备或对象的数据隔离。

### 学习资源

- [pandas时间序列教程](https://pandas.pydata.org/docs/user_guide/timeseries.html)
- [statsmodels时间序列分析](https://www.statsmodels.org/stable/tsa.html)
- [SciPy信号处理](https://docs.scipy.org/doc/scipy/tutorial/signal.html)

### 达标标准

- 时间数据始终按时间排序；
- 能生成滞后和滚动特征且不使用未来信息；
- 能实现时间滚动验证；
- 能从轴承信号提取基本时域和频域特征；
- 能避免同一设备样本同时进入训练和测试。

## 7. 优化模型编程

### 需要学习

- 使用PuLP或OR-Tools定义变量、目标和约束；
- 0-1、整数和连续变量；
- 指派、排班、装箱和路径示例；
- 求解状态、运行时间、最优间隙；
- 大规模模型的时间限制；
- 启发式算法的重复实验；
- 独立约束校验器。

### 学习资源

- [Google OR-Tools](https://developers.google.com/optimization)
- [PuLP文档](https://coin-or.github.io/pulp/)
- [Pyomo文档](https://pyomo.readthedocs.io/)
- [SciPy优化教程](https://docs.scipy.org/doc/scipy/tutorial/optimize.html)

### 达标标准

- 能实现一个小型指派或排班模型；
- 能读取并解释求解器状态；
- 能重新计算目标函数值；
- 能编写与求解器相互独立的约束检查函数；
- 启发式算法至少运行多次并报告最好值、均值和波动；
- 结果不可行时能定位违反的具体约束。

### 需要学习

- Git初始化、提交、分支、合并和回退；
- 项目目录和命名；
- 实验ID与配置文件；
- 日志、随机种子和运行时间；
- 结果保存与图表映射；
- 一键运行入口与双备份。

### 学习资源

- [Pro Git中文版](https://git-scm.com/book/zh/v2)

### 达标标准

- 能通过Git找回一个稳定版本；

- Notebook重启并全部运行后结果一致；
- `main.py`或等价入口能生成核心结果；
- 代码、数据和输出至少保存两份。

## 四、推荐项目目录

```text
project/
├─ data_raw/          # 原始数据，只读
├─ data_processed/    # 脚本生成的数据
├─ src/               # 通用函数
├─ experiments/       # 模型实验
├─ outputs/
│  ├─ figures/        # 论文图片
│  └─ tables/         # 论文表格
├─ paper/             # 论文文件
├─ result_registry.csv

├─ main.py
└─ README.md
```
