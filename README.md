## 修改规则

1. 每个人主要维护自己的学习计划文件。
2. 修改前先获取 GitHub 上的最新版本。
3. 每完成一部分学习内容，及时更新完成状态和备注。
4. 提交时写清楚修改内容，例如：`更新成员2第一周学习进度`。
5. 涉及三人分工或共同计划调整时，在[讨论记录](docs/meeting-notes/讨论记录.md)中记录。
6. 不直接删除其他组员的内容；如有不同意见，先在讨论记录中说明。

## 推荐状态标记

- `[ ]` 尚未开始
- `[~]` 正在学习
- `[x]` 已完成
- `[!]` 遇到问题

## 推荐提交流程

```text
获取最新内容 → 修改自己的学习计划 → 检查修改 → 提交 → 推送到GitHub
```
